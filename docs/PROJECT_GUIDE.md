# Руководство по приложению «Сеть связи»

[Локальный запуск, база и сборка карты](./LOCAL_RUN.md).

## Работа с интерфейсом

### Карта и схема

Откройте **Меню → Карта**. Флажок «Показать карту» включает карту, снятие флажка включает схему. В режиме карты можно выбрать слой границ регионов или округов. Нажмите «Применить». Кнопка справа в верхней панели повторно загружает данные сети.

Карта показывает объекты с координатами. Схема показывает узлы и линии без привязки к координатам. Кнопка «+» на узле или вложенном объекте раскрывает его состав, если у него есть дочерние элементы. После успешной повторной загрузки данных открытые паспорта закрываются.

### Паспорта

- Клик или наведение примерно на секунду открывает паспорт узла или линии. Повторный клик по узлу сворачивает его паспорт, а следующий клик возвращает карточку. Повторный клик по линии закрывает её открытый паспорт.
- Кнопка «−» сворачивает карточку, а «×» закрывает её. Клик по вкладке сворачивает или разворачивает карточку. Вкладки можно перетаскивать. При переключении карты и схемы паспорта сохраняются.
- Перетащите паспорт за заголовок, чтобы разместить его в стороне от объекта. В заголовке можно использовать клавиши со стрелками. Кнопка привязки возвращает карточку к объекту.
- Клик по пустому месту сворачивает паспорта. «Открыть все» разворачивает паспорта, «Скрыть все» сворачивает их, «Закрыть все» закрывает также вкладку «Подсветка».
- Паспорт узла показывает код, позывной и класс A, B или C, если они заданы. «Схема УС» открывает дерево состава. Остальные действия узла и действия линии показывают заглушки. Паспорт линии показывает идентификатор и, при наличии, её концы и подпись отношения.

### Подсветка по фильтрам

Откройте **Меню → Подсветить → По фильтрам**. В окне доступны регионы и военные округа, классы узлов, линии между двумя территориями и типы интерфейсов каналов. Если выбраны территория и класс, подсвечиваются узлы этого класса на выбранной территории. Отдельные условия для линий и каналов могут добавить совпадения. Линии подбираются по территориям их концов. Подсветка по интерфейсу использует имя и свойства канала, а связанные с ним линии — явные отношения в данных.

«Скрыть иное» оставляет подходящие объекты и необходимые для показа линий концы. Нажатие «Применить» сворачивает окно во вкладку «Подсветка». Кнопка «−» сохраняет черновик фильтров во вкладке. Крестик закрывает вкладку, а применённый вид сохраняется до сброса или применения другого режима. Вкладку «Подсветка» можно перетаскивать среди паспортов.

### Ручная подборка

Откройте **Меню → Подсветить → Ручной выбор** и нажмите «Выбрать узлы». Окно свернётся, а в левом верхнем углу карты или схемы появится панель со счётчиком. Клик по узлу добавляет его, повторный клик снимает отметку. При редактировании видны узлы, скрытые предыдущей подсветкой.

Ctrl + клик меняет подборку сразу. Если удерживать Ctrl около 300 мс, панель появится заранее. После отпускания клавиши временная панель исчезает, если подборка в этом быстром режиме не менялась. После изменения панель остаётся для применения или отмены.

- **«Подсветить выбранные»** выделяет узлы подборки. Остальные объекты видны приглушёнными.
- **«Показать только выбранные»** оставляет выбранные узлы и линии между ними.
- **«Отмена»** закрывает панель и возвращает ранее применённый вид. Подборка остаётся доступной для дальнейшего редактирования.
- В большом окне виден список узлов. Крестик убирает узел из подборки и сразу обновляет применённую ручную подсветку. «Очистить выбор» сбрасывает ручную подборку. Пункт меню «Сбросить подсветку» очищает и ручной выбор, и фильтры.

Подборка и настройки фильтров хранятся раздельно в состоянии страницы. Применение одного режима заменяет отображаемый результат другого. Подсветка сохраняется при переключении карты и схемы в пределах главной страницы.

## Маршруты и архитектура

| Маршрут | Назначение | Компонент |
| --- | --- | --- |
| `/` | Карта, схема сети, паспорта и подсветка | `src/pages/NetworkPage.jsx` |
| `/objects/:objectId` | Дерево состава объекта по его исходящим отношениям СФЭ | `src/pages/ObjectPage.jsx` |
| `/lines/:lineId` | Демонстрация состава ЛС1 или заглушка для другого ID | `src/pages/LinePage.jsx` |

`src/main.jsx` запускает React, а `src/App.jsx` задаёт маршруты. Главная страница получает объекты и отношения через `GET /api/graph`. При разработке Vite пересылает запрос в Express. В локальном режиме Express обслуживает и интерфейс, и API. `src/utils/api.js` обрабатывает HTTP-ошибки и некорректные ответы.

СФЭ — запись IMC, представляющая узел, линию, оборудование или другой объект. Сервер читает объекты из `imc.thematic_layers_sfes`, прямые отношения из `imc.thematic_layers_sfe_linkings` по полю `id_ls_sfe`, а координаты из `imc.network_node_locations`. Название берётся из `vr_code`. В ответе `nodes` содержат `id`, `lng`, `lat` и `data` с метаданными, а `edges` — `id`, `source`, `target` и `label`. `unlocatedCount` сообщает, у скольких объектов отсутствуют координаты. Связи с записями внешних справочников не преобразуются в рёбра.

У линии есть собственный UUID. Например, в базе ЛС1 связана с УС1 и УС2 двумя отношениями. Интерфейс может показать одну линию между узлами. Её экранный ID отличается от UUID ЛС1 и от ID исходных отношений. Поле `lineId` связывает представления линии с записью IMC и её паспортом.

| Участок | Где смотреть |
| --- | --- |
| Главная схема с раскрываемым составом | `buildExpandableNetwork` в `src/utils/fullNetwork.js`, `NetworkNode.jsx`, `RoutedEdge.jsx` |
| Карта и проекция узлов и линий | `PhysicalMap.jsx`, `src/utils/mapGraph.js`, `MapGraphOverlay` в `NetworkPage.jsx` |
| Паспорта, ключи и раскладка карточек | `Passport.jsx`, `src/utils/passports.js`, состояние в `NetworkPage.jsx` |
| Меню и подсветка | `Toolbar.jsx`, `HighlightDialog.jsx`, `src/utils/networkHighlight.js` |
| Дерево состава | `ObjectTree.jsx`, `src/utils/objectTree.js` |
| Демонстрационные данные ЛС1 | `src/data/lineExample.js`, `LinePage.jsx` |
| API, SQL и структура базы | `server/index.js`, `database/migrations/` |

На схеме двухконечная линия отображается ребром, а линия с другим числом концов может отображаться отдельной карточкой с подключениями. Состав узлов строится по отношениям «состоит из». На карте линия строится между объектами с координатами. Правила будущей детализации каналов описаны в [проектном предложении](./LINK_COLLAPSING_DESIGN.md).

Демонстрация ЛС1 доступна напрямую по адресу `/lines/53ff7800-a047-48dd-ba59-50daff0e98d3`. Она содержит 20 объектов и 27 отношений со стабильными локальными ID `LS1-001`–`LS1-020` и `LS1-R01`–`LS1-R27`. В ней есть реестр объектов, фильтры и просмотр маршрута канала. Допущения исходного эскиза отмечены в самом примере. Демонстрация использует данные из исходников.

## API

| Метод и адрес | Назначение |
| --- | --- |
| `GET /api/health` | Проверить доступность PostgreSQL |
| `GET /api/graph` | Получить объекты, отношения и число объектов без координат |
| `GET /api/graph?layerId=<UUID>` | Ограничить выборку одним тематическим срезом |
| `GET /api/nodes/:id/properties` | Получить свойства объекта с учётом сохранённых и заданных по умолчанию значений |
| `PUT /api/nodes/:id/location` | Создать или обновить координаты существующего объекта из JSON с полями `lng` и `lat` |

API записи координат проверяет UUID и диапазоны долготы от −180 до 180 и широты от −90 до 90. В текущем паспорте формы редактирования координат нет. Граф перечитывается по запросу, для обновления открытой главной страницы используйте кнопку справа. Объекты и отношения сервер читает двумя параллельными запросами без общего снимка базы.

## Картографические ресурсы

| Ресурс в `public/maps` | Назначение |
| --- | --- |
| `network-overview.pmtiles` | Обзорные плитки до масштаба 8 |
| `network-areas.pmtiles` | Детальные плитки с масштаба 9 в зонах вокруг сохранённых координат |
| `russia-outline.geojson` | Контур для базового режима |
| `military-districts.geojson`, `russia-regions.geojson` | Границы для отображения и геометрия для фильтров подсветки |
| `fonts/`, `sprites/` | Шрифты подписей и значки |

MapLibre получает части архивов PMTiles через HTTP. `mapLayers.js` переключает режимы карты, а `boundaryOutlines.js` удаляет технические замыкающие линии на меридиане ±180° из отрисовываемых контуров. Исходные полигоны используются для заливки и географических проверок. В базовом режиме виден отдельный контур России, а в режимах округов и регионов также отображаются границы стран базовой карты. [Источники, лицензии и условности отображения](../public/maps/ATTRIBUTION.md).

## Проверка изменений

`npm test` проверяет API, импорт, преобразования графа, паспорта, подсветку и картографическую геометрию. `npm run lint` проверяет исходники, `npm run build` создаёт `dist`.

В браузере проверьте «Меню → Карта», оба слоя границ, карту и схему, открытие и сворачивание паспортов, подсветку по округу и классу, ручной выбор и удаление узла из списка. Отдельно проверьте переход к составу узла и прямой маршрут демонстрации ЛС1.
