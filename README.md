# Сеть связи

Веб-приложение для просмотра узлов и линий связи на офлайн-карте и интерактивной схеме. Интерфейс использует React, Vite, MapLibre и React Flow. Сервер Express читает данные IMC из PostgreSQL.

## Быстрый запуск

Если зависимости, локальная база и ресурсы карты уже подготовлены, выполните `npm start` или запустите `start-local.cmd` на Windows. Откройте <http://127.0.0.1:4173/>. Express обслуживает интерфейс, API и ресурсы карты на одном адресе.

Для разработки установите зависимости командой `npm ci`, настройте `.env` по образцу `.env.example` и запустите `npm run dev:api` и `npm run dev` в отдельных терминалах. Адрес интерфейса появится в выводе Vite.

[Подготовка базы, офлайн-карты и локальный запуск](./docs/LOCAL_RUN.md).

## Работа с сетью

- **Меню → Карта**. Флажок «Показать карту» переключает карту и схему. В этом же разделе выбираются границы округов или регионов. Изменения вступают в силу после «Применить».
- **Паспорта**. Открываются по клику или наведению с задержкой. Несколько карточек можно перемещать и сворачивать во вкладки. В паспорте узла действие «Схема УС» открывает его состав.
- **Меню → Подсветить**. Вкладка «По фильтрам» позволяет выбрать территорию, класс узла, линии между территориями и интерфейсы каналов. Во вкладке «Ручной выбор» можно собрать подборку кликами по узлам или сочетанием Ctrl + клик.
- **Демонстрация ЛС1**. На странице состава линии доступен отдельный пример с оборудованием, физическими соединениями и маршрутом канала. Остальные страницы состава линий пока содержат заглушки.

[Подробное руководство по интерфейсу, архитектуре и API](./docs/PROJECT_GUIDE.md).
