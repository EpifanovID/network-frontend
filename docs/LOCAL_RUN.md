# Запуск без интернета

## На этом компьютере

1. Убедитесь, что служба PostgreSQL запущена.
2. Откройте `start-local.cmd` двойным щелчком из папки проекта. Альтернатива — команда `npm start` в терминале из этой папки.
3. Дождитесь сообщения `Local application listening on http://127.0.0.1:4173`.
4. Откройте в браузере `http://127.0.0.1:4173/`.

Окно запуска должно оставаться открытым. Для остановки нажмите Ctrl+C. Vite и отдельный API для этого режима запускать не требуется; режим разработки остаётся доступен.

`npm start` сначала выполняет локальную сборку (`prestart`), затем запускает Express. Он обслуживает интерфейс, API и ресурсы карты с одного адреса. Установки или скачивания пакетов в командах запуска нет. Если сборка уже готова: `node server/index.js --serve-frontend`.

Сервер принимает подключения только с этого компьютера (`127.0.0.1`). Порт по умолчанию 4173; изменить его можно через `LOCAL_PORT` в `.env`. Тогда используйте адрес с новым портом из терминала. Параметр `API_PORT` относится к отдельному режиму API при разработке.

## Что требуется заранее

- Установленные Node.js и npm, папка `node_modules` с зависимостями проекта.
- Запущенный локальный PostgreSQL с данными и схемой IMC.
- `.env` с `DATABASE_URL`, указывающим на локальную базу (`127.0.0.1` или `localhost`). Удалённая база требует доступной сети.
- Архивы `public/maps/network-overview.pmtiles` и `public/maps/network-areas.pmtiles`, три GeoJSON, шрифты и спрайты в `public/maps`.

При подготовке этого режима настройки подключения указывают на локальный PostgreSQL, архивы и остальные ресурсы карты присутствуют. При переносе проверьте их наличие заново.

Карта загружает данные с локального сервера. Ссылки на источники в атрибуции открываются по нажатию пользователя. Первичная установка пакетов, скачивание исходной географии и пересборка PMTiles из внешних данных — отдельные подготовительные операции, которым может понадобиться интернет. Запуск приложения их не выполняет.

HTTP-запросы к `127.0.0.1` идут внутри компьютера. Не открывайте `dist/index.html` через `file://`.

## Перенос на другой компьютер без интернета

Заранее подготовьте совместимую установку Node.js/PostgreSQL, зависимости и ресурсы карты. PMTiles и `.env` исключены из Git: одного клонирования недостаточно. Базу перенесите отдельно штатным резервным копированием и восстановлением PostgreSQL, затем укажите её параметры в `.env`. Папка `database/migrations` содержит структуру, но не текущие данные базы.

## Проверка и ошибки

- `http://127.0.0.1:4173/api/health` должен вернуть `status: ok`, `database: connected`.
- Проверьте карту, округа, регионы, граф без карты, паспорта, состав узла и ЛС1.
- Если API не запускается, проверьте службу PostgreSQL и `.env`.
- `Missing local file`: проверьте указанный ресурс в `public/maps` и выполните `npm run build`.
- Порт занят: остановите предыдущий экземпляр или измените `LOCAL_PORT`.
- Если `npm` не найден, установите Node.js с npm и заново откройте терминал.

Работа с живой базой сохраняется: координаты записываются в PostgreSQL. Этот режим не заменяет базу демонстрационными данными.
